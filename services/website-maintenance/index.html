02 / WordPress

WordPress maintenance & administration

Running a WordPress website requires more than publishing content. WordPress core, plugins, and themes need to be maintained to help keep the website secure, compatible, and reliable.

I can maintain existing WordPress websites, including websites that I did not originally develop. The service can cover routine maintenance as well as investigation and resolution of technical issues.

  • Plugin and theme updates

  • Security and configuration reviews
  • Backup management
  • Form and email troubleshooting
  • Broken functionality troubleshooting
  • Performance and technical optimization
03 / Migration

Website & Hosting Migration

Moving a website to a new hosting provider or server requires more than copying files. The website environment, database, configuration, DNS, SSL, and key functionality should be checked after the move.

Website & Hosting Migration is available as a one-time technical service and can also be followed by ongoing website maintenance and administration.

The migration will be carefully planned and executed with the objective of maintaining minimum downtime and ensuring a smooth transition to the new hosting environment.

Migration scope

  • Website files and database transfer
  • WordPress configuration and environment checks
  • Theme and plugin compatibility checks
  • New hosting/server configuration support
  • DNS and SSL configuration support
  • Post-migration testing and verification

Email migration is handled separately when email services are hosted outside the website/server environment.
